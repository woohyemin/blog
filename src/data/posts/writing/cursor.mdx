최근에 **Cursor**라는 AI 코드 에디터를 사용해 보게 되었다.

코드 자동 완성뿐만 아니라, 마치 AI 페어 프로그래머와 협업하며 개발하는 듯한 느낌을 받아서 개인적으로 Cursor를 사용해 본 경험은 꽤 인상 깊었다.

아직 Cursor의 모든 기능을 활용해 보진 못했지만, 사용하면서 경험한 내용을 바탕으로 정리해 보려고 한다.

# Cursor란?

Cursor는 VS Code를 기반으로 만든 **AI 중심의 코드 에디터**이다. 단순한 자동완성 기능을 넘어서, **자연어로 코드를 수정하거나 생성하고, 리팩토링과 디버깅까지 지원하는** 도구이다.

기본적으로 OpenAI의 GPT-4 API를 활용하지만, 다른 LLM들을 선택해서 사용도 가능하다.

# 주요 기능

## 🔍 자연어로 코드 검색 및 수정

```text
"이 함수에서 사용자 인증 로직 추가해 줘"
```

예를 들어, 이런 문장을 입력하면 AI가 해당 함수에 적절한 인증 로직을 삽입하고 해당 로직을 적용할지 말지 선택할 수 있다.

## 🧠 전체 코드 맥락 이해

Cursor는 파일 단위가 아닌 프로젝트 전체를 맥락으로 이해하고 코드를 제안한다. 따라서 함수 하나만 바꾸는 것이 아니라, 그 함수가 쓰이는 컴포넌트나 훅까지도 연관 지어 제안한다.

또한 코드를 수정하는 과정에서 에러가 발생한 경우, 자동으로 새로운 코드로 수정하여 에러를 개선하는 과정도 확인할 수 있었다.

# 사용한 후기

## ✅ 장점

프로젝트 전반을 고려해서 코드를 작성해 주기 때문에 너무 편리했고, 심지어 React에서 Next.js로 세팅을 변경하는 것조차 가능했다는 점이 놀라웠다.

AI에게 모든 것을 맡길 수는 없겠지만, 잘 활용한다면 훨씬 효율적으로 개발할 수 있겠다고 생각되었다.

## ❌ 단점

무료 버전도 있긴 하지만 기능이 제한적이어서 아쉬웠다. 프로 버전을 사용하게 된다면 비용이 다소 부담스럽게 느껴질 수도 있다.

아무래도 AI를 완전히 신뢰하기는 어렵기 때문에, Cursor가 제안한 코드를 검토하는 과정은 필요하다.
